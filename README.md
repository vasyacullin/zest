# Zest 🍋

**Zest** is a lightweight, blazing fast, GPU-accelerated immediate mode GUI library for Rust. .

## ✨ Features

* **Immediate Mode Simplicity:** No complex state syncing. Your UI is described where it lives, .
* **GPU-Accelerated:** Built with hardware acceleration in mind (`) for butter-smooth 60+ FPS interfaces.
* **Blazing Fast:** Written in pure Rust with minimal overhead, low memory footprint, and instant startup times.
* **Developer Friendly:** Clean API, single-file styling, and hassle-free integration into existing event loops.
